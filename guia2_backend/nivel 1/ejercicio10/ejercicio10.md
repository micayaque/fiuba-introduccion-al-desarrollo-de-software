## ​Ruta Raíz y Navegación

Implementa la ruta `/` para ofrecer enlaces a otros endpoints, facilitando la navegación manual.

* Renderizar un template con enlaces a `/saludo` y `/datos`.

```html
<body>
    <ul>
        <li><a href="/saludo">Ir a /saludo</a></li>
        <li><a href="/datos">Ir a /datos</a></li>
    </ul>
```
* Verificar el funcionamiento desde el navegador.
