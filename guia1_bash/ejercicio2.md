### 2- Cómo accede a la ayuda de Linux

Los comandos que pueden utilizarse son los siguientes:

```bash
man comando #Muestra el manual del comando completo

info comando #Muestra la documentación tipo manual en formato más detallado y navegable

comando --help #Muestra una ayuda rápida del comando

help comando #Muestra ayuda de comandos internos del shell (como cd, echo, etc.)

whatis comando #Muestra una descripción de una línea del comando

apropos palabra #Busca en los manuales comandos relacionados con una palabra
```
